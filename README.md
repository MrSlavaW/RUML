# RUML (RimWorld Universal Mods Localization)

Официальный монорепозиторий мода **RUML** и каталога переводов сообщества для RimWorld.

---

## Архитектура монорепозитория

```text
RUML/
├── Mod/                   # Исходный код и бинарники ядра мода для RimWorld
│   ├── About/             # Метаданные мода (About.xml)
│   ├── Assemblies/        # Скомпилированные DLL (RUML.dll)
│   ├── 1.5/ & 1.6/        # Версионные сборки
│   ├── LoadFolders.xml    # Конфигурация загрузки
│   └── Source/            # Исходный код C# (UI, менеджер папок, аудитор, облако)
├── Translations/          # Каталог открытых XML-переводов сообщества
│   └── [НазваниеМода]/[Язык]/[Автор]/
├── packs/                 # Автоматически генерируемые архивы переводов (CI/CD)
├── manifest.json          # Единый реестр переводов для внутриигрового Cloud Hub
└── .github/               # Автоматизация и пайплайны GitHub Actions
```

---

## О моде RUML (Core)

**RUML** — это универсальное автономное модульное ядро-загрузчик для RimWorld:
- **Горячее переключение:** включение и отключение любых переводов на лету без перезапуска игры.
- **Облачный хаб (GitHub):** скачивание, обновление и удаление переводов сообщества прямо из настроек игры с изоляцией в AppData.
- **Аудитор любых модов:** сканирование любых установленных активных модов с расчётом процента покрытия и экспортом отчётов.

## Как добавить свой перевод в сообщество

1. Создайте каталог: `Translations/<ИмяМода>/<Язык>/<ВашНик>/`
2. Добавьте файл `info.json`:
```json
{
  "packageId": "author.modpackageid",
  "version": "1.0.0",
  "description": "Описание перевода"
}
```
3. Поместите папки `DefInjected/` и/или `Keyed/`.
4. Создайте Pull Request в ветку `main`.

После слияния GitHub Actions автоматически упакует архив в `packs/` и обновит `manifest.json`. Игроки смогут скачать ваш перевод в один клик прямо в игре!
